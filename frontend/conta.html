Registros

    Trazer dados do sistema antigo

    Busca tudo que está no servidor antigo (Render + MySQL) e salva no Firebase. Faça isso uma vez só, logo depois de começar a usar a versão nova. Os dados atuais deste sistema serão substituídos pelos do servidor antigo.

    Backup

    Os dados já ficam salvos online, mas é bom guardar uma cópia extra de vez em quando (Google Drive ou pendrive). Importar um backup substitui todos os dados, em todos os aparelhos.
